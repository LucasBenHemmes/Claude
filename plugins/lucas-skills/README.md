# lucas-skills

Mijn eigen skills. Elke skill is een map in `skills/` met een `SKILL.md`:

```
skills/
  mijn-skill/
    SKILL.md        # frontmatter (name, description) + instructies
    scripts/...     # optioneel
```

Verhoog `version` in `.claude-plugin/plugin.json` als je iets wijzigt, zodat updates worden opgepikt.
